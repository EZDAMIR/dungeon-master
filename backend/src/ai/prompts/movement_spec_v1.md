# Sprint 4A movement spec v1

Return only MovementSpecV1 for the supplied exercise_key and display_name.
Use allowed operations and valid MediaPipe landmark names. Declare every feature,
in dependency order; no hidden max_* metrics. For rep extrema use scope=rep.
relative_y is first point Y minus second point Y; screen Y increases downward.
Angles are degrees; normalized features divide by body scale. Build a reachable
complete cycle returning to start with stable transition holds. Include concrete
short corrections and calibration/ready/good_rep/tracking_recovery/complete cues
in ru, kk, en. Primary <=56 Unicode characters, movement labels <=32, secondary
<=120, title <=48. No executable expressions, code, new layouts or clinical claims.
Prefer simple observable movements. Complex/unobservable movements may be manual.
