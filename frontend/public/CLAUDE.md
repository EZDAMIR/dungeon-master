# Static browser assets

Scope: `frontend/public/`. Extends [parent instructions](../CLAUDE.md).
Read ancestor guides and the repository architecture documents before edits.

## Purpose

Serve icons and verified local inference assets through Vite's public directory.

## Code rules

- Keep favicon.svg and icons.svg as browser assets; use Vite BASE_URL when constructing runtime URLs.
- Model binaries and public/mediapipe/ are generated by scripts/prepare-vision-assets.mjs and remain gitignored.
- Do not put credentials, recordings, user landmarks or application logic in public assets.

## Dependencies

Runtime code may reference asset URLs; public files must not import application modules.

## Verification

Commands run from `frontend/` unless specified otherwise.
Run `npm run build`; for asset changes also verify file contents under the deployed base path.
